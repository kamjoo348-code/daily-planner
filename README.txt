# پلنر روزانه — نسخه PWA

همه موارد این پوشه را در ریشه مخزن GitHub Pages بارگذاری کنید؛ پوشه icons باید به همان شکل حفظ شود.

ساختار:
- index.html
- manifest.webmanifest
- service-worker.js
- icons/icon-192.png
- icons/icon-512.png
- icons/icon-512-maskable.png
- icons/icon-180.png

پس از Commit، در مخزن GitHub به Settings > Pages بروید و مطمئن شوید Branch برابر main و Folder برابر /(root) است.
